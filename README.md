# shane-mathew.com

Personal website of Shane Mathew: economics, research and data.

Live at **https://shane-mathew.com**, hosted on GitHub Pages from the `main` branch.

## Structure

- `index.html` – the single-page site
- `assets/css/main.css` – styles
- `assets/js/main.js` – navigation, animations and portfolio filters
- `assets/img/` – photos, portfolio covers and the link-preview image (`og-image.jpg`)
- `papers/` – PDFs linked from the Portfolio section
- `CNAME` – custom domain for GitHub Pages (don't delete)

## Updating the site

```bash
git pull
git add .
git commit -m "Describe the change"
git push
```

Changes go live within a minute or two.
